Arguments

Agenda

  1. Arguments

Arguments are Reasons

  • An argument is an attempt to provide a reason in support of some conclusion.
  • An argument, in this sense, is not a verbal altercation. It is not a fight. It is not a debate. It is not a shouting match.
  • We won’t be arguing with each other in this class. We will be thinking about and assessing the strength of arguments.

Standard Form

  • The textbook presents arguments in standard form.
  • In standard form, an argument is a list of statements:
    • the premises,
    • perhaps some subconclusions,
    • and, always last, the main conclusion.
  • The word ‘So’ is used to mark subconclusions and conclusions.

Exercises

Give them a few arguments. Ask them to identify the premises, subconclusions, and main conclusion. Ask them to attempt to articulate the reasoning from premises, via subconclusions, to main conclusion.

Validity and Invalidity

  • When the logic of an argument is good, the conclusion follows from the premises.
  • That means that, if the premises are true, the conclusion has to be true too.
  • So, when the logic is good, if you want to deny the conclusion, you have to deny at least one of the premises.

Modus Ponens

Argument

  • MP1. If Bjarki is a dog, then Bjarki is a mammal.
  • MP2. Bjarki is a dog
  • MP3. So, Bjarki is a mammal.
  • This form argument is always valid: the conclusion follows from the premises; if the premises are true, the conclusion must be true as well.
  • If the conclusion, MP3, is false, then either MP1 is false or MP2 is false.

Affirming the Consequent

Argument

  • AC1. If Bjarki is a dog, then Bjarki is a mammal.
  • AC2. Bjarki is a mammal.
  • AC3. Bjarki is a dog
  • This form of argument is not valid: the conclusion does not follow from the premises; the premises can both be true, and yet the conclusion false. For example, imagine that Bjarki is a cat.

Validity and Invalidity

Validity
An argument is valid when its conclusion follows from its premises, in the sense that it is impossible for the premises to be true but the conclusion false.
Invalidity
An argument is invalid when its conclusion does not follow from its premises, in the sense that it is possible for the premises to be true but the conclusion false.

Happily, all the arguments presented in the book are valid!

Responding to Valid Arguments

  • All the labeled arguments in the book are valid.
  • This means that, if you want to reject the conclusion of one of these arguments, you must also reject the truth of at least one of the premises.

Conditionals

A conditional is an ‘if… then…’ statement. The ‘if’ part is called the antecedent and the ‘then’ part the consequent:

  • If Bjarki is a dog, then Bjarki is a mammal.
  • If eating meat causes suffering, then eating meat is morally wrong.
  • If the world is flat, then one must be careful not to sail off the edge.

Conditionals are not Arguments

Argument

  • CO. If the world is flat, then one must be careful not to sail off the edge.
  • AR. The world is flat. So one must be careful not to sail off the edge.

Do you see the difference between (CO) and (AR)?

Conditionals in Arguments

Conditionals often appear as premises in arguments. They offer a bridge between two claims. As we have already seen, they provide the bridge needed to perform Modus Ponens:

Argument

  • FW1. The world is flat.
  • FW2. If the world is flat, then one must be careful not to sail off the edge.
  • FW2. So, one must be careful not to sail off the edge.

This argument is valid, but its conclusion is false. The conditional, FW2, is plausibly true. But FW1 is false.

Conditionals in Arguments

A conditional is a bridge that can be traveled in both directions. Here is another valid argument involving FW2:

Argument

  • FW1*. One need not worry about sailing off the edge of the world.
  • FW2. If the world is flat, then one must be careful not to sail off the edge.
  • FW3*. So, the world is not flat.

This form of argument is called Modus Tollens.

Counterexamples

Argument

  • BH1. A six-week-old embryo has a beating heart
  • BH2. It’s always immoral to kill something that has a beating heart
  • BH3. So, it’s immoral to kill a six-week-old embryo

Notice how BH2 says that something is always immoral. Can you come up with any counterexamples?

Counterexamples

Argument

  • CN1. A six-week-old embryo isn’t conscious
  • CN2. It’s never wrong to kill something that isn’t conscious
  • CN3. So, it isn’t wrong to kill a six-week-old embryo

Notice how CN2 says that something is never wrong. Can you come up with any counterexamples?
